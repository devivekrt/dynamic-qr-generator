# Dynamic QR Code Generator — Catalyst schema

Create these tables in Zoho Catalyst Data Store. `ROWID` is generated by
Catalyst. Relationships and ownership are enforced by the backend.

## Businesses

| Column | Type | Required | Notes |
|---|---|---:|---|
| `ROWID` | Catalyst system column | Yes | |
| `name` | Var Char | Yes | |
| `email` | Var Char | Yes | Lowercase; unique in application logic |
| `password_hash` | Text | Yes | Salted password hash |
| `slug` | Var Char | Yes | Unique business slug |
| `created_at` | Date-Time | Yes | |

## QrCodes

| Column | Type | Required | Notes |
|---|---|---:|---|
| `ROWID` | Catalyst system column | Yes | |
| `business_id` | Var Char | Yes | `Businesses.ROWID` |
| `name` | Var Char | Yes | Owner-facing QR name |
| `slug` | Var Char | Yes | Permanent public slug; unique in application logic |
| `created_at` | Date-Time | Yes | |

## Contents

Each QR has exactly one current destination. Enforce uniqueness on
`qr_code_id` in Catalyst if available, and in backend logic regardless.

| Column | Type | Required | Notes |
|---|---|---:|---|
| `ROWID` | Catalyst system column | Yes | |
| `qr_code_id` | Var Char | Yes | `QrCodes.ROWID` |
| `business_id` | Var Char | Yes | `Businesses.ROWID` |
| `title` | Var Char | Yes | |
| `type` | Var Char | Yes | `text`, `link`, `image`, or `pdf` |
| `text_value` | Text | No | Used for `text` |
| `url_value` | Text | No | Used for `link` |
| `file_id` | Var Char | No | Catalyst File Store ID |
| `original_name` | Var Char | No | Uploaded file name |
| `created_at` | Date-Time | Yes | |
| `updated_at` | Date-Time | Yes | |

Create one Catalyst File Store folder and set its ID as
`CATALYST_FILESTORE_FOLDER_ID`.
